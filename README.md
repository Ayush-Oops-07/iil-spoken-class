# Indian Institute of Language (IIL) — Gopalganj

Official website for the **Indian Institute of Language (IIL)**, Gopalganj, Bihar.
Founded and mentored by **Aftab Alam**.

- **Official Instagram:** [https://www.instagram.com/iilbyaftabalam/](https://www.instagram.com/iilbyaftabalam/)
- **Helpline / WhatsApp:** +91 91028 24592
- **Location:** Near Kailash Hotel, Yadopur Road, Gopalganj, Bihar 841428

## Features
- **Design System:** Frosted glassmorphism, glossy white theme, responsive typography.
- **Auto-Scrolling Student Reels:** Interactive carousel with auto-advance, sound toggle, and full-screen video lightbox.
- **Campus Gallery:** Editorial photo grid with keyboard-navigable Lightbox modal.
- **Course Directory:** 6 structured learning tracks with direct WhatsApp enquiry integration.
- **Founder Profile:** Mentorship credentials and direct connection with Aftab Alam.
- **Integrated Google Maps:** Interactive location iframe with one-click directions.
- **Conversion-Optimized Enquiry:** Instant WhatsApp message generator with live field validation.

## Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production Build
```bash
npm run build
npm start
```
